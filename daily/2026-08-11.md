# 2026-08-11 — Sub-$10 Margin Bug Root Cause & Fix

## Session Summary

Eric laporan posisi $3/$1 masih kebuka meski hard rule MIN_MARGIN=$10 sudah di-set. Bug ini sudah "diperbaiki" beberapa kali sebelumnya tapi selalu balik lagi. Audit menyeluruh dilakukan ke semua jalur order-placement di seluruh sistem (n8n workflows, systemd services, cron/timer, container openclaw).

### Root Cause

Node **"Kimi Approved?"** (IF node) di workflow n8n `TRD - Sigma Scalping` cek field `execution_allowed` dari response `sigma_orchestrator.py` `/veto` endpoint. Field ini **TIDAK memperhitungkan critical_flags** (termasuk red flag margin < $10). Field yang benar adalah `real_order_allowed` (= execution_allowed AND no critical_flags).

**Bukti kunci:** `workflow_history` n8n nunjukin node ini terakhir diubah **12 Juni 2026** — sebelum fix hari ini, tidak pernah disentuh. Artinya semua perbaikan sebelumnya (constant MIN_MARGIN di file Python, validasi $50 di Junior Trader) menambal lapis LAIN, tapi gate n8n ini tetap bocor terus — itu kenapa bug selalu kambuh.

### Fix Applied (15:13 UTC)

- Export workflow `qUjwDi48068STPTK` via `n8n export:workflow` CLI
- Patch `Kimi Approved?` node: `$json.execution_allowed` → `$json.real_order_allowed`
- Import balik via `n8n import:workflow`, restart container `markasbesar-n8n-1` biar efektif
- Workflow reaktivasi otomatis, jalan normal tiap 15 menit
